# Повторная проверка FeedbackAgent в TextCraft

Этот пакет содержит код и числовые результаты отдельного повторного опыта. Он проверяет, помогает ли явное описание открытых команд TextCraft.

Основной опыт курсовой закрыт на 4416 запусках. Повторный опыт закрыт отдельно на 2724 запусках. Их журналы и результаты не объединяются.

Здесь доступны два действия. Можно проверить опубликованные числа без модели. Можно отдельно подготовить новую реплику с разрешения владельца подписки.

Новая реплика получает новые ответы модели. Она не воспроизводит сохранённые ответы и не открывает закрытый журнал.

## Что сравнивали

В опыте участвовали 40 разных игровых целей. Для каждой цели запускали четыре варианта программы. Поэтому получилось 160 эпизодов.

Эпизод означает одну попытку программы решить игровую задачу. Все варианты получали одинаковое исходное состояние одной цели.

| Вариант | Как программа выбирает действие | Решено целей | Обращений к модели |
| --- | --- | ---: | ---: |
| `feedback` | Исходный FeedbackAgent без нового пояснения команд | 21/40 | 935 |
| `feedback_open_commands` | FeedbackAgent с явным пояснением команд | 32/40 | 686 |
| `grounding_only` | Пояснение команд и проверка цитаты критика, без двух проб | 34/40 | 686 |
| `raw_actor` | Пояснение команд и первоначальный исполнитель, без критика | 37/40 | 417 |

В трёх последних вариантах пояснение было одинаковым. Оно объясняло смысл пустого списка `available_actions`. Такой список не запрещает команды TextCraft.

Пояснение требовало возвращать одну команду `get`, `craft` или `inventory`. Оно запрещало заменять команду предложением об отсутствии доступных действий.

На один эпизод выделяли не более 32 обращений к модели. Предельная длина составляла 100 игровых действий. Реальное число действий зависело от затрат программы.

Все 160 эпизодов завершены. Из них 124 завершились успехом, а 36 остановились по лимиту обращений. Платный API не использовался.

Моделью была `gpt-5.6-luna` с параметром рассуждения `low`. Обращения выполнялись через Codex CLI 0.147.0 и подписку ChatGPT.

Уточнение инструкции повысило результат FeedbackAgent на этом наборе: с 21 до 32 решённых целей. Однако варианты без двух проб решили больше целей.

Этот опыт не подтверждает преимущество самих проб. Он также не устанавливает превосходство над мировыми лидерами или методами, которые здесь не запускали.

Исходный публичный пакет в `src/` сохранён. Повторный опыт использует отдельную папку `frozen_runner`. Его изменения не подменяют основную реализацию курсовой.

## Проверка опубликованных результатов без модели

Откройте папку репозитория. Для этой проверки достаточно Python 3.11 или новее. Вход в Codex и загрузка игровых данных не нужны.

Для нового клонирования используйте ветку повторного опыта:

```sh
git clone --branch codex/textcraft-retest-20261123 https://github.com/MrHammerWin/feedback-receptivity-study.git
cd feedback-receptivity-study
python -B retests/textcraft/verify_numeric.py
```

Если репозиторий уже открыт, выполните только последнюю команду из его корня. Не клонируйте проект поверх существующей папки.

В Windows PowerShell можно вызвать установленный Python 3.12 так:

```powershell
py -3.12 -B retests/textcraft/verify_numeric.py
```

Успешная проверка выводит `passed: true`, 40 целей, 160 эпизодов и 2724 записанных обращения. Поле `new_model_calls` должно равняться нулю.

Проверка сверяет все файлы пакета с `release_manifest.json`. Затем она пересчитывает результаты каждого варианта и парные сравнения.

Парное сравнение сопоставляет два варианта на одной и той же цели. Его единица анализа здесь одна цель, а не отдельная строка CSV.

Проверка также сверяет ограничения эпизодов и исключение 18 прежних целей. Она не читает приватные журналы и не доказывает происхождение модельных ответов.

Для парной статистики используется существующий файл `analysis/paired_statistics.py`. Его код не изменён. Показатели повторного опыта не добавляются в исходные `source_data/` репозитория.

## Какие доказательства доступны

Полный исполнявшийся пакет имеет идентификатор:

```text
d03d898cc15f86ea6f01fa9ffe17f041bc9339a1792ce98d829d55cd62a1da08
```

Он вычислен по именам и содержимому всех 12 файлов пакета. Открытая копия сохраняет эти байты.

Манифест целей также сохранён без изменения. Он содержит идентификаторы и контрольные суммы, но не тексты рецептов или ответы модели.

Проверка прежних целей опубликована в сокращённом виде. В ней оставлены только идентификаторы целей и контрольные суммы открытых файлов.

Тексты прежних выгрузок, пути компьютеров и первичные записи не включены. Поле `source_file` в сокращённых списках содержит отметку недоступности исходной записи.

Эту отметку требует формат исходного проверяющего кода. Она не обозначает опубликованный исходный файл. Ограничение явно указано в самих списках.

Открытая проверка подтверждает согласованность опубликованных списков. Она не позволяет независимо подтвердить полноту приватных прежних журналов.

Оригинальная и открытая проверки имеют разные контрольные суммы. Обе суммы указаны в `source_record.json`. Открытый файл не выдаётся за неизменённый приватный оригинал.

Данные не подписаны цифровой подписью. В пакет не включены ключи, разрешения подписки, журнал попыток и полные диалоги модели.

## Подготовка новой реплики

Этот раздел требует нового разрешения владельца подписки. Он не разрешает расходовать остаток закрытой кампании.

Для новой реплики используйте Linux или WSL2. Исходный модуль учёта запуска использует Unix-модуль `fcntl`. Нативный Windows для модельного запуска не поддерживается.

В записанном окружении использовался CPython 3.12.3. Версии прямых библиотек указаны в `requirements-retest.txt`. Это не полный снимок всех зависимостей.

В Linux-терминале из корня проекта создайте окружение:

```sh
python3.12 -m venv .venv-retest
. .venv-retest/bin/activate
python -m pip install -r retests/textcraft/requirements-retest.txt
```

Установка библиотек требует сети. Она не вызывает языковую модель. TextCraft использует свои данные из установленного пакета.

Для обращения к модели нужен Codex CLI 0.147.0. Настройте вход через собственную подписку ChatGPT:

```sh
npm install -g @openai/codex@0.147.0
codex login
codex login status
```

Наличие подписки не гарантирует доступность исторической модели `gpt-5.6-luna`. При её отсутствии остановитесь. Замена модели означает другое исследование.

Задайте порядок хеширования до старта Python:

```sh
export PYTHONHASHSEED=0
```

После нового разрешения владельца ресурсов подготовьте отдельный каталог. Замените `replica-owner-01` собственным новым идентификатором:

```sh
python -B retests/textcraft/prepare_replica.py --directory local/textcraft-replica-01 --campaign replica-owner-01 --max-launches 5120 --i-authorize-subscription-use
```

Эта команда не вызывает модель. Она проверяет версии библиотек и исходные состояния всех четырёх вариантов на 40 целях.

При несовпадении исходного состояния команда останавливается до создания разрешения. Не заменяйте ожидаемую контрольную сумму ради продолжения.

TextCraft может менять отвлекающие рецепты между средами исполнения. Поэтому новая реплика может остановиться даже при совпадении цели и seed.

Подготовка создаёт отдельную копию кода в `local/textcraft-replica-01/runner/src/`. Она меняет только строку `CAMPAIGN` в копии `experiment.py`.

Новый идентификатор отделяет журнал владельца от закрытого исследования. Такая копия получает собственную контрольную сумму исходников. Она сохраняется в `preparation.json`.

Остальная логика, инструкции модели и лимит эпизода сохраняются. Подготовка не меняет `frozen_runner` или исходный пакет `src/`.

Число 5120 задаёт верхний предел новых попыток. Это 40 целей, четыре варианта и максимум 32 обращения на эпизод.

Отказы тоже расходуют разрешение. Остаток не возвращается автоматически. Внутренние ограничения процесса не увеличивают этот сохраняемый предел.

Существующий каталог подготовки использовать нельзя. Программа не перезаписывает прежние разрешения, контрольные точки и журналы.

## Явный запуск модели

Следующая команда начинает реальные обращения. Выполняйте её только в пределах нового согласованного разрешения:

```sh
bash retests/textcraft/run_replica.sh local/textcraft-replica-01 --start
```

Скрипт проверяет подготовленный код и конфигурацию. Он блокирует параллельный запуск той же кампании через `flock`.

Затем программа проверяет исходные состояния повторно. В среду передаётся одна итоговая команда после завершения выбора действия.

Повтор сохранённых модельных ответов не используется. Новые ответы могут отличаться от исходных. Совпадение названия облачной модели не гарантирует неизменные веса.

Программа не заменяет ошибочную команду правильным действием. Она также не изменяет ответы и оценки исходной курсовой.

| Путь внутри каталога новой кампании | Содержимое |

| `checkpoint.json` | Предел, после которого новые старты запрещены |
| `preparation.json` | Отличие копии кода и её контрольная сумма |
| `inputs/` | Открытые зафиксированные цели и сокращённая проверка исключений |
| `results/run.json` | Версии среды, исходников и входных данных |

Эти файлы остаются локальными. Они могут содержать диалоги и пути компьютера. Их нельзя автоматически включать в публичную поставку.

При транспортном отказе программа останавливает новые старты. Незавершённый эпизод не повторяется скрыто. Причину отказа нужно разобрать отдельно.

Нельзя удалять журнал, менять старую контрольную точку или считать неудачный запуск бесплатным. Новая реплика требует собственного завершения и анализа.

## Границы проверки этого пакета

Проверка опубликованных чисел выполняется без модели. Подготовка новой реплики проверяет среду, но не обещает завершение будущих вызовов.

Открытые числовые строки не заменяют первичные диалоги. Контрольные суммы не доказывают научную истинность результатов сами по себе.

Собственный код и инструкция подготовлены с существенной помощью ИИ. Автоматические проверки не являются внешним научным рецензированием.
